A Integração Contínua é uma prática que automatiza a união e o teste do código de toda a equipe frequentemente para evitar erros no sistema, como divergência entre códigos de pessoas que tentaram mexer na mesma parte simultaneamente. Nesse processo, as branches são essenciais porque permitem que cada desenvolvedor crie um ambiente isolado para trabalhar em novas funções sem estragar o código principal. Por fim, o Pull Request funciona como a etapa final de controle de qualidade, onde a equipe revisa as alterações feitas nessa branch, discute melhorias e aprova a integração segura do novo código ao projeto. Geralmente o processo de Pull Request é acompanhado por um Code Review, onde é analisado o que foi desenvolvido (usado principalmente no contexto de código de software).
